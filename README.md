# Gaudia-Itinera  
A website to buy tickets to a fictional theme park.  

## How does it work?  
Simply head over to the administrator page to delete, modify or create new tickets.  
On the orders page you'll be able to see how many orders have been made on the website.  

On the user page you'll be able to buy tickets and view them in your shopping cart, upon buying them, it will be registered in the orders page of the administrator site.  

If you delete all existing tickets and return to the homepage the ticket's default JSON will load.  

## How do I install and run the project? (GitHub version)  
When you're in the repository, press the button that says `Code`.  
Once you press on it, there should be a HTTPS link that you can copy and `git clone` on your computer.  
Afterwards, you must run `index.html` with a live server, otherwise the ticket will not load for you.  
The website should now be up and running for you!
